# Eyewear developer handoff

Open `START-HERE.html` in a browser to match original references, studio photos and the selected lifestyle photos visually.

Every image filename begins with the same product ID and descriptive product name used by its folder. P01–P06 are internal handoff IDs, not manufacturer SKUs. M95 is the label on the supplied shield supplier sheets; the other names describe appearance.

## Which photos to use

- `01-ecommerce-front`: main category/product listing image.
- `02-ecommerce-angle` or `02-ecommerce-detail`: second gallery image.
- `03-lifestyle-*`: selected ski-resort, après-ski or chalet lifestyle image.
- `alternatives/04-alternative-lifestyle-original`: earlier lifestyle version, retained as an optional alternative.
- `references-do-not-upload`: original supplied photos for identification only.

Use `product-map.json` for the complete filename mapping. Do not upload the reference images or all alternatives automatically. The lifestyle photos are generated campaign imagery; they do not establish ski-protection specifications.
